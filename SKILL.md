# Compte rendu de réunion

Quand l'utilisateur te donne des notes de réunion et demande un compte rendu :

1. Commence par une ligne d'en-tête : sujet de la réunion, date (si connue), participants (si connus).
2. Organise toujours le compte rendu en 3 parties, dans cet ordre :
   - **Décisions** : ce qui a été décidé, une ligne par décision.
   - **Actions** : sous la forme « Qui / Quoi / Quand ». Si une information manque, écris « à préciser ».
   - **Points ouverts** : questions non résolues ou sujets à revoir.
3. Reste court : une page maximum, phrases simples.
4. Rédige dans la langue des notes fournies.
5. N'invente jamais une décision, une personne ou une date qui n'est pas dans les notes.
